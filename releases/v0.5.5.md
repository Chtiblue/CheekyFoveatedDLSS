**Cheeky Foveated DLSS v0.5.5**

This update adds per-game UEVR activation, improves OpenXR gaze and headset menu compatibility, and adds an optional fix for motion-vector blurriness since v0.5.4.

- **Enable Cheeky per game in UEVR:** the plugin now waits to load its processing runtime until you check **Enable Cheeky for this game** in **LuaLoader → Cheeky Foveated DLSS**. New profiles start disabled, and the choice is saved per game, including with a global UEVR installation. Disabling stops processing on the next host frame; re-enabling preserves settings. Restart the game to fully unload the runtime.
- **Clearer stereo controls:** groups calibration and manual full-eye mapping under **Stereo Eye Mapping**. Calibration runs automatically for non-Manual methods; eye-order inversion is hidden with automatic stereo alignment. Choose **Manual** in the mapping method selector to enable **First DLSS view is right eye**. **Height offset** now adjusts fixed and eye-tracked placement, including simulated gaze, AFW and tracking-loss fallback. Existing nonzero height settings now also affect live gaze.
- **OpenXR gaze compatibility:** improves gaze action-space setup for runtimes such as Galaxy XR and adds guarded gaze input for IL-2. Two advanced options, **Manual** mapping and **Independent OpenXR gaze**, are available for troubleshooting and remain off by default. Check the red alignment border in both eyes when using manual mapping. Independent gaze requires an application restart after changing it and can conflict with games that initialize their own input later.
- **Standalone headset menu and input:** improves Cyberpunk 2077 OpenXR controller bindings, menu input ownership and pointer handling, including queued clicks and custom host bindings.
- **Optional motion-vector blur fix:** adds **Fix motion-vector blur** for DX12 DLSS-SR with input-resolution motion vectors, plus DLSS preset J. The fix is off by default and adds GPU work; enable it if your preset produces blurriness.
- **D3D12 stability:** avoids copy-observer faults with opaque graphics interposers used by VR mods.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place. Open **LuaLoader → Cheeky Foveated DLSS** and check **Enable Cheeky for this game** if the profile has not been enabled yet.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking.

DLSS-NR still requires a compatible `nvngx_dlssnr.dll`, supplied separately or available through a compatible NVIDIA App runtime override.
