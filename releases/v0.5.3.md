**Cheeky Foveated DLSS v0.5.3**

This update improves OpenXR eye tracking and calibration, adds LibOVR/Pimax support, and enables DX11 transport in the UEVR plugin.

- **OpenXR eye tracking:** fixes extension detection when other API layers prevent a reliable capability check, with retries that preserve gaze support.
- **OpenXR headset menu:** improves curved-menu capability detection and fallback when extension availability is unknown.
- **Startup diagnostics:** persistent OpenXR startup logs are included in support reports.
- **LibOVR support:** adds stereo alignment and eye calibration for Oculus PC SDK games, including R.E.A.L. VR's LibOVR mode. Pimax eye tracking uses the game's existing PVR session without requiring OpenXR.
- **Alternating-eye calibration:** pairs legacy AER eye submissions and handles failed submissions and swap-chain recreation.
- **Calibration matching:** fixes false vertical-flip detection during reacquisition after resizing.
- **DX11 output dimensions:** preserves the DLSS feature's created output dimensions when evaluation parameters are reused, with guards for late injection and private features.
- **UEVR DX11 transport:** enables DX11 -> DX12 transport and DLSS-NR in DX11 games. Enable transport under **DLSS-NR (experimental)**; SR can also use transport without NR.

LibOVR calibration currently supports D3D11 submissions, including D3D12 rendering transferred into D3D11 textures. Native LibOVR D3D12 swap-chain calibration and Vulkan support remain deferred. New LibOVR and UEVR transport paths have automated coverage; in-game/headset validation remains outstanding.

**Downloads:** Standalone and UEVR ZIPs only. Both include the matching OpenXR installer.

**Updating:** Exit the game before replacing files.

- **Standalone:** copy `CheekyFoveatedDLSS/` and **one** loader, `dxgi.dll` or `version.dll`, into the game's executable folder. Do not copy both loaders or overwrite another mod's loader. For Vulkan, also update `CheekyVulkanLayer.dll` and preserve `CheekyFoveatedDLSS/Vulkan/`. Open settings with F8 or your configured menu key.
- **UEVR:** extract the complete UEVR package into the game's UEVR configuration directory, preserving `plugins/` and `scripts/`. Update both DLLs and the Lua script together. Saved settings can stay in place.
- **OpenXR:** run the included `OpenXR/CheekyOpenXRSetup.exe` to update the shared layer alongside Cheeky, including on headsets without eye tracking.

DLSS-NR still requires a compatible `nvngx_dlssnr.dll`, supplied separately or available through a compatible NVIDIA App runtime override.
